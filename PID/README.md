# PID Tuner - Автоматический подбор параметров ПИД-регулятора

Приложение на C++ с использованием Qt 6 (или Qt 5.15+) для автоматического расчёта коэффициентов ПИД-регулятора методом Циглера-Николса.

## 📋 Описание

Приложение позволяет:
- Вводить параметры объекта управления (коэффициент усиления K, постоянная времени T, транспортное задержание τ)
- Автоматически рассчитывать коэффициенты ПИД-регулятора (Kp, Ki, Kd) методом Циглера-Николса
- Оценивать характеристики замкнутой системы (время регулирования, перерегулирование, устойчивость)
- Визуализировать переходные процессы разомкнутого объекта и замкнутой системы

## 🔧 Метод расчёта

**Метод Циглера-Николса по реакции на ступенчатое воздействие (Process Reaction Curve)**

Объект аппроксимируется моделью первого порядка с запаздыванием:
```
W(s) = K * exp(-τ*s) / (T*s + 1)
```

Формулы для ПИД-регулятора:
```
Kp = 1.2 * T / (K * τ)
Ki = 0.6 / (K * τ)
Kd = 0.6 * T / K
```

### Ограничения метода:
- Применим только для объектов с S-образной переходной характеристикой
- Не подходит для объектов с большим запаздыванием (τ/T > 0.5)
- Может давать чрезмерно агрессивную настройку (перерегулирование ~40%)

## 📦 Зависимости

- **CMake** ≥ 3.16
- **Qt** ≥ 5.15 (требуется модуль Charts) или Qt 6.x
- **C++** стандарт 17

### Установка зависимостей

#### Ubuntu/Debian:
```bash
sudo apt-get update
sudo apt-get install cmake g++ qtbase5-dev qtcharts5-dev
# или для Qt 6:
sudo apt-get install cmake g++ qt6-base-dev qt6-charts-dev
```

#### Windows (с использованием vcpkg):
```bash
vcpkg install qtbase:x64-windows qtcharts:x64-windows
```

#### macOS (с использованием Homebrew):
```bash
brew install cmake qt
```

## 🚀 Сборка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ktasked/PID.git
cd PID
```

### 2. Создание директории сборки
```bash
mkdir build
cd build
```

### 3. Конфигурация проекта
```bash
# Для Qt 6 (по умолчанию)
cmake ..

# Или явно указать путь к Qt
cmake -DCMAKE_PREFIX_PATH=/path/to/qt ..
```

### 4. Компиляция
```bash
cmake --build . --config Release
```

### 5. Запуск
```bash
# Linux/macOS
./PIDTuner

# Windows
Release\PIDTuner.exe
```

## 💡 Использование

1. Запустите приложение
2. Введите параметры объекта:
   - **K** - коэффициент усиления (положительное число)
   - **T** - постоянная времени в секундах (положительное число)
   - **τ** - транспортное задержание в секундах (неотрицательное число)
3. Нажмите кнопку **"Рассчитать"**
4. Просмотрите результаты:
   - Коэффициенты ПИД-регулятора
   - Ожидаемые характеристики системы
   - Графики переходных процессов
5. При необходимости нажмите **"Сбросить"** для очистки данных

## 🛠 Расширение функциональности

### Добавление нового метода расчёта

1. Добавьте новый метод в класс `PIDTuner`:
```cpp
// include/pidtuner.h
PIDCoefficients calculateNewMethod() const;

// src/pidtuner.cpp
PIDCoefficients PIDTuner::calculateNewMethod() const {
    // Ваша реализация
}
```

2. Вызовите новый метод в `MainWindow::onCalculateClicked()`

### Поддержка ввода передаточной функции

Для расширения ввода коэффициентами передаточной функции:
1. Добавьте поля ввода для числителя и знаменателя
2. Реализуйте метод аппроксимации к модели K/(Ts+1)*exp(-τs)
3. Используйте существующие методы расчёта

## ⚠️ Обработка ошибок

Приложение включает защиту от:
- Некорректных входных данных (отрицательные K, T)
- Деления на ноль (при τ → 0 используется предельный случай)
- Числовой нестабильности (ограничение интеграла, анти-windup)
